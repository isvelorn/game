# Client runtime contract (draft v0.1)

## Обязательные границы

- **Input → intent:** WASD/клавиши/мышь преобразуются в команды движения/действия без права определять результат.
- **Camera:** третье лицо, ближе к спине персонажа, горизонтальный widescreen кадр, свободное направление 0–360°; точные проекция и угол обзора ещё не приняты.
- **Presentation:** 3D scene → terminal-cell framebuffer (`character, fg, bg, depth`) → ANSI/VT output adapter. Фреймбуфер не равен авторитетному состоянию.
- **Local/offline vs online:** возможность локального server-loop обсуждается; нельзя утверждать, что отдельный MMORPG-сервер обязателен с первого прототипа.
- **Runtime UI:** полосы/хотбар/чат отдельно от render grid; адаптация к реальному размеру TTY и узким экранам.

## Совместимость

C99 как исходная цель; переход на C11 только через ADR. Платформенные адаптеры POSIX (`termios`) / Windows console APIs — логические слои. Детектирование VT/цвета: conservative fallback; отключение mouse/focus/bracketed paste корректно при выходе/сигналах. Настоящий key-up во многих терминалах недоступен: управление должно иметь fallback с проверкой эргономики.

Поддержку Windows/macOS/Linux/FreeBSD и SSH **проверяем**, а не объявляем обеспеченной. Отдельный графический шейдер не заменяет требования запускаться в терминале.
