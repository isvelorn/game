# Renderer / Input Spike · протокол проверки

**Задача:** не перепутать красивую генерацию изображения с реально достижимым терминальным FPS.

## Сцена

Земля, 10–30 процедурных деревьев, персонаж из примитивов, камера третьего лица, плавные повороты и перемещение, частицы. Никаких внешних 3D-моделей как обязательного шага.

## Кандидаты

TermGL (C99) — проверить доступные примитивы, сборку, лицензию, обновление буфера, поддержку клавиатуры/цвета/OS. Альтернативы допускаются после сравнения. Renderer adapter должен оставаться заменяемым.

## Метрики и тесты

- Размеры: 80×24, 120×40, 160×50 и реальное разрешение; частота кадров, p50/p95 frame time.
- Загрузка CPU, байты ANSI на кадр, падение FPS при полном обновлении, реальный SSH-трафик.
- Управление: событие отпускания/повтора, скорость и инерция, мышь и fallback.
- Освещение, occlusion/z-buffer, символы по форме, сохранение читаемого силуэта.
- Ресайз, неподдерживаемый truecolor, альтернативный буфер, CTRL+C, потеря TTY.
- Перекрёстный smoke test Windows/macOS/Linux/FreeBSD; протокол фиксирует реальные результаты и непроверенные платформы.

**Gate:** только после прототипа выбрать библиотеку и программу эволюции рендеринга.
