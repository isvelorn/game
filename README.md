# ISVELORN · Game Client

Планируемый кроссплатформенный терминальный клиент 3D ASCII/ANSI Action RPG на C. **Пока архитектурный каркас: исполняемого клиента ещё нет.**

- [Контракт клиента](docs/client.md)
- [Программа исследования терминального рендеринга](docs/rendering-research.md)
- [Общая архитектура](https://github.com/isvelorn/.github/blob/main/docs/architecture.md)

## Границы

Клиент отвечает за ввод, камеру от третьего лица, символьное отображение, локальное предсказание/интерполяцию (если будет нужно), интерфейс и доступность. Клиент **не является** источником истины для урона, предметов, денег, наград или прогресса.

Цель — Windows, macOS, Linux, FreeBSD, в том числе через подходящий терминал/SSH, **после тестирования**. Свободное перемещение и поворот на 360° не предполагают движения по клеткам. Blender не является обязательным этапом создания контента.

**TermGL и другие библиотеки — кандидаты**, не утверждённые зависимости. Ближайшая задача: честный прототип ANSI-вывода, ввода и 3D-сцены с замерами производительности.
